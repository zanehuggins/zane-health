RUNNER WORKOUT VIDEO PACKAGE

Open index.html in Safari or Chrome. Tap an exercise to see its pop-up.

IMPORTANT: Video files are NOT included yet. Download only videos whose reuse/license terms you have verified, and place them into the videos folder with the exact filenames listed in video_manifest.json.

The HTML5 video players will loop matching MP4 files locally, with no external iframes. For best results on iPhone, save/unzip the folder in Files and open index.html in Safari; some iOS file previews restrict local linked media.
