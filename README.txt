LEAN RUNNER WEB APP

Open index.html in a browser, or serve this folder with: python3 -m http.server 8000
Then visit http://localhost:8000.

The overview links to seven separate day pages in days/. Strength days show clickable exercise cards with primary and supporting muscle groups. Each card opens a dialog with three movement diagrams, an embedded YouTube demonstration, a direct YouTube link, a source link and form cues. Videos require an internet connection. No local MP4 files are needed. The weekly tracker saves checkmarks in browser storage.

Video references are listed in video_manifest.json. The short Joy2Move clips use start and end times from the source pages. Embedded playback depends on YouTube availability and each video owner's embed settings; the direct video link remains available.

The local SVG diagrams are in diagrams/. Eleven exercise sets come from Workout Guide by Bryl Lim; some are based on Everkinetic art. The floor-press set was drawn for this project. All are credited under CC BY-SA 4.0 in diagrams/credits.json; the license text is in diagrams/CC-BY-SA-4.0.txt.
