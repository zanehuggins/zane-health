# Exercise diagrams

This directory contains three SVG movement frames for each of the 12 strength exercises. They are served locally so diagrams remain visible even when video playback is unavailable.

Eleven sets were copied without modification from [Workout Guide](https://github.com/avidevper/workout-guide-svgs) by Bryl Lim. Some frames adapt earlier [Everkinetic](https://github.com/everkinetic/data) artwork. The exact source pages and upstream details are recorded in [credits.json](credits.json).

The dumbbell floor press frames are original illustrations made for this project. They show a side view with one arm visible for clarity.
